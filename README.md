TURBO CIRCUIT - Group 6

Game Idea:
Race opponents, avoid obstacles, collect upgrades, and earn championship points.

Controls:
- Arrow keys = Move your car
- R = Restart race
- L = Show leaderboard
- Q = Quit game

Concepts Used:
- Bubble Sort - ranks racers by lap time
- Insertion Sort - adds new results to leaderboard
- Selection Sort - finds best lap time
- Tuple - stores starting position
- Set - stores unlocked tracks and achievements
- Dictionary - stores racer data
- Recursion - traverses the circuit
